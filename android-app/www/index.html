Welcome to Wishes

Wishes runs on your family's own server. Type its address to connect.

The same address you open Wishes at in a browser. For example wishes.example.com or 192.168.1.20:3000.

Your server asked for a sign-in before showing Wishes, so the app couldn't double check it. If that's expected, carry on.

Where do I find the address?
  • Ask whoever set up Wishes for your family.
  • If you run it yourself on Unraid or Docker, it's your server's address and port, like 192.168.1.20:3000. That only works on your home Wi‑Fi (or a VPN).
  • To use it anywhere, put Wishes behind a reverse proxy with https, then use that address.
